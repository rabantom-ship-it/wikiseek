# Zenodo: DOI y URL pública

Zenodo (CERN) es gratuito, asigna DOI de DataCite y sirve para que ORCID y Google Scholar tengan un identificador estable.

1. Crea una cuenta en https://zenodo.org/
2. **New upload**.
3. Sube el PDF del libro o, si está en KDP Select, solo un capítulo de muestra.
4. Resource type: **Book** o **Book chapter**.
5. Metadatos:
   - Título y subtítulo.
   - Autor: Abanto Marín, Roger Alejandro.
   - Año: 2026.
   - Editorial.
   - ISBN (si lo tiene).
   - Idioma: español.
   - Palabras clave.
   - Descripción.
6. Licencia: si el autor acepta acceso abierto, **CC BY-NC-ND 4.0**; si no, “All rights reserved”.
7. Related identifiers: la URL pública de WikiSeek.
8. **Publish**. Zenodo asigna un DOI (ej. `10.5281/zenodo.XXXXXXX`).
9. Añade el DOI a ORCID: **Works → + Add → Add work with DOI**, o importa desde DataCite.
10. Añade el DOI a la ficha del libro en WikiSeek.

## Advertencia

- Si el eBook está en **KDP Select**, no subas el PDF completo: la exclusividad cubre el formato digital.
- Si el libro está gratis en Zenodo y a la venta en Amazon, Amazon puede igualar el precio a $0. Como ya no importan las regalías, es aceptable; pero decide conscientemente.
- No uses el DOI de un capítulo como si fuera el DOI del libro completo.
