# Paquete para la UNMSM

Contiene:
- `ficha.md` — ficha bibliográfica de los tres libros.
- `resumen.md` — resúmenes de 150–250 palabras.
- `carta-biblioteca.md` — carta modelo para la Biblioteca Central.
- `correo-profesores.md` — correo modelo para docentes.
- `licencia.md` — opciones de licencia.

## Ruta recomendada

1. **Fondo Editorial UNMSM**: presenta el proyecto de coedición o segunda edición.
   http://sisbib.unmsm.edu.pe/BibCentral/pdf/ProcedimientoManuscritosAlFondoEditorial.pdf
2. **Biblioteca Central Pedro Zulen**: entrega dos ejemplares y la ficha; pide catalogación y WorldCat.
3. **Repositorio institucional**:
   - https://gestionrepo.unmsm.edu.pe/
   - https://repositorio.unmsm.edu.pe/
   - https://sisbib.unmsm.edu.pe/
4. **Departamento de Psiquiatría**: presenta los libros, ofrece una clase o taller y pide adopción como texto.

## Nota

El repositorio de la UNMSM es principalmente de tesis y colecciones especiales. Pregunta explícitamente por el **depósito de libros** y por la **autorización para el depósito de obra**. Si no aceptan libros comerciales, propone una edición OA con sello UNMSM o un capítulo dentro de una colección institucional.
