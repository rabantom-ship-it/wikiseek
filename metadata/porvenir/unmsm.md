# Repositorio UNMSM

## Antes de depositar

1. Tramita el **ISBN** en la BNP; mientras tanto, puedes depositar con **DOI** y “ISBN en trámite”.
2. Licencia ya definida: **CC BY 4.0**.
3. Ten a mano:
   - PDF final;
   - portada;
   - resumen de 150–250 palabras;
   - palabras clave;
   - índice;
   - ficha del autor;
   - ORCID.

## Pasos

1. Entra a https://gestionrepo.unmsm.edu.pe/ y crea una cuenta o inicia sesión.
2. Busca la comunidad o colección de tu facultad (Medicina / Psiquiatría).
3. Elige **Nuevo ítem** y el tipo **Libro** o **Objeto de aprendizaje**.
4. Rellena metadatos:
   - Título y subtítulo.
   - Autor: Abanto Marín, Roger Alejandro.
   - Fecha: 2026.
   - Editorial: Nexo Clínico.
   - ISBN.
   - Idioma: español.
   - Derechos: la licencia elegida.
   - Resumen.
   - Palabras clave.
   - DOI: 10.5281/zenodo.24205039.
   - URL pública.
5. Sube el PDF y la portada.
6. Envía para revisión.

## Si el repositorio solo acepta tesis

Pregunta por:
- **Colecciones Especiales**;
- **Fondo Editorial UNMSM**;
- una **edición OA con sello UNMSM**;
- un **capítulo** dentro de una colección institucional.
