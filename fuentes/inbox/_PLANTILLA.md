# Plantilla de nota para WikiSeek

# Título de la nota

Escribe aquí el contenido. Puedes usar:

- Listas con guiones.
- **Negritas** y *cursivas*.
- Enlaces como [texto](https://ejemplo.com).
- Tablas con el formato `| columna | columna |`.

La primera línea con `# ` se usa como título del artículo. El nombre del archivo define la dirección web: por ejemplo, `mi-nota.md` se convierte en `nota-mi-nota.html`.
